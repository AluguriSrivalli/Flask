# Flask — Learning & Projects

This repository collects my Flask learning notes and small example projects so you can explore how Flask apps are structured and run.

## Quick start (minimal)
1. Create a virtual environment and activate it:
   - Unix/macOS:
     ```
     python3 -m venv venv
     source venv/bin/activate
     ```
   - Windows (PowerShell):
     ```
     python -m venv venv
     .\venv\Scripts\Activate.ps1
     ```
2. Install Flask:
   pip install Flask
   
3. Run the example WSGI app:
   python WSGI/app.py
